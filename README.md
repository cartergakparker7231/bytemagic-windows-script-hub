## Overview

ByteMagic is a Windows-first Roblox script executor built for local execution, Luau bytecode-related workflows, and quick access from a clean desktop application. Its interface stays intentionally compact and includes a practical script hub without adding unnecessary visual complexity.

The project targets 64-bit Windows 10 and Windows 11 systems. It is intended for users who want a small-footprint executor with a straightforward layout, script hub functionality, and support for Roblox script execution tasks.
